Untuk memakai format atau nama lain, buka index.html di VS Code, cari nama file di atribut src, lalu ganti nilainya sesuai nama file. JPG, PNG, dan WebP bisa dipakai; pastikan ejaan dan ekstensi di src sama persis dengan file. Setelah menambahkan gambar, muat ulang halaman di browser. Jika file belum tersedia, kartu menampilkan latar ilustrasi tanpa ikon gambar rusak.
